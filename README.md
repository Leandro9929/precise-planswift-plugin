# precise-planswift-plugin

PlanSwift plugins.

- [`page-renamer/`](page-renamer/README.md): **Precise Page Renamer**. Reads sheet numbers and titles from plan title blocks, previews and corrects page names, batch-renames PlanSwift pages through PlanSwift's COM interface, and restores original names. Windows test checklist: [`page-renamer/TESTING.md`](page-renamer/TESTING.md).
